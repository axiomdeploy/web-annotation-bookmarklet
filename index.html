⬡ ANNOTATE

A screen annotation bookmarklet — pen, shapes, laser pointer & spotlight for any website.

Installation

  1. Bookmark this page (Ctrl+D) — name it Annotate; the green hexagon icon is stored with it.
  2. Press Copy code, right-click the bookmark → Edit → replace the URL with the copied code → Save.
  3. Open any website and click the bookmark. Enjoy ✅

Shortcuts

1 – 5Pen · Box · Arrow · Laser · Eraser
` (backtick)Click-pass — page stays fully interactive
ZLock / unlock page scrolling
XClear all drawings
Ctrl + ZUndo last stroke
C / SCycle color · Save PNG
H / RSpotlight · Rainbow laser
EscClose Annotate completely

The toolbar tucks itself away when the mouse moves away and returns on hover. Press ▼ in the header for the hexa pill. Double-click the Laser button for rainbow mode. Pen supports stylus pressure. The bookmarklet code on this page is encoded automatically — drag, copy and preview always produce the exact same, working bookmark.
